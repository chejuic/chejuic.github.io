健檢工具列

把下面這顆按鈕拖到書籤列即完成安裝，不必安裝任何軟體。

健檢工具列

怎麼用

  1. 登入健檢系統 newhmc.ntuh.gov.tw，開到健檢清單頁（例如 /HMC/Diagnosis/Medicine）。
  2. 按一下書籤 → 工具列出現在右下角，同時把清單上每位病人的 病歷號 → regID 掃進本機記錄。
  3. 輸入病歷號 → 按「健檢報告」或「心電圖」（按 Enter 等於按第一顆）。

為什麼健檢系統不需要填 session

newhmc 是 ASP.NET MVC + Forms Authentication，登入狀態靠 cookie。 書籤是在你已經登入的那個分頁裡跑的，cookie 自動跟著送，所以不需要任何 session 欄位。

唯一需要人給值的是第四代報告：它在 hchihisaw 這台別的主機上， 吃網址參數 SESSION，跟健檢系統的 cookie 無關。從門診系統網址列把 SESSION= 後面那一段複製過來，貼進工具列第三列的框，會存在這台瀏覽器裡。

它做什麼、不做什麼

做掃描本頁的連結與表格，配對出 病歷號 → regID
做依你輸入的病歷號組出網址、開具名視窗（連按不會開一堆分頁）
不做不點頁面上任何按鈕、不填任何欄位、不觸發 postback、不存檔
不做沒有任何網路行為（無 fetch / XHR / sendBeacon / WebSocket）
