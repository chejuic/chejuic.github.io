門診工具列 v1

醫令頁 · SOAP 頁 · 第四代報告，三邊一鍵互跳

安裝：把下面這顆拖到書籤列（拖一下就好，不必下載、不必安裝任何東西）

門診工具列

拖不動的話：在書籤列按右鍵 → 新增分頁 → 網址欄貼上 dist/bookmarklet.txt 的內容。

怎麼用

  1. 在門診醫令開立或 SOAP 畫面上，按書籤列的「門診工具列」。
  2. 右下角出現一條工具列，上面先顯示目前這位病人的姓名與病歷號，看清楚再按。
  3. 三顆按鈕各自開一個具名視窗，連按不會開出一堆分頁。搭配雙螢幕：一邊 SOAP、一邊醫令。
  4. 再按一次書籤，或按工具列上的 ✕，就收起來。

它做什麼、不做什麼

做依目前網址與頁面上的隱藏欄位，組出三個目標網址並開新視窗
不做不點頁面上任何按鈕、不填任何欄位、不觸發 postback、不存檔
不做沒有任何網路行為（無 fetch / XHR / sendBeacon / WebSocket），不送出任何資料

三道守門（任一不符就停手）

網域hchhisaw.ntuh.gov.tw（新竹）或 hbiohisaw.ntuh.gov.tw（生醫）
頁面ConfirmDiagnosisOrder / EnterChiefCompliant / OpenClinicsByExamine
參數網址必須有 SESSION

不符時只會跳一個說明視窗，不會有任何動作。

已知限制

  • SOAP 與醫令兩顆需要網址裡有 AccountIDSE；從診間清單直接按會是灰的，先點進病人再用。
  • SOAP 頁沒有 PersonID，第四代報告會改用表頭的病歷號（兩種都吃，已實測）。
  • 省的是點擊數，不是伺服器回應時間。
